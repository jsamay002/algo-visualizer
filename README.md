# Algorithm Visualizer

Interactive web app that visualizes common competitive programming algorithms step by step. Built to help students understand how algorithms work through real-time visual feedback, pseudocode, and operation breakdowns.

## Demo

![Screen Recording 2026-03-11 at 10 58 23 PM](https://github.com/user-attachments/assets/a7f814e6-d6c7-464c-b214-6e73c934c867)

## Algorithms

**Searching & Sliding Window**
- Binary Search, Two Pointers, Prefix Sums, Sliding Window

**Sorting**
- Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort

**Graph Algorithms**
- BFS, DFS, Dijkstra's, Topological Sort

**Data Structures & DP**
- Union-Find (DSU), Dynamic Programming (LIS)

## Features

- Step-by-step visualization with play/pause controls
- Pseudocode display in Python, C++, and Java
- Adjustable speed and array/graph size
- Operation highlighting showing current step progress
- Custom input support for arrays and graphs

## Usage

Open `index.html` in a browser. Select an algorithm from the sidebar, configure the input, and step through the visualization.
